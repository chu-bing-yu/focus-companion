# 角色陪伴番茄钟（Roche 插件）

首页待办清单 + 每日目标 → 点待办进入番茄钟 → 聊天单独一屏。
五种角色模式、四项监督权限、AI 聊天（自定义提示词）。
当前版本 **0.13.0**。语音、主聊天注入在后续阶段。

界面分三屏，都在「专注」这个 App 内：

- **首页**：今日目标进度、待办清单、进行中的计时条；点待办只选中，不自动跳计时页；点 ▶ 只带着待办去计时页。「进行中」条可点，按默认页回聊天/倒计时。重开插件先回首页
- **计时页**：计时环、右上角计时设置、模式切换、角色监督；角色只显示不可点，换角色到全局设置改默认；模式只改本轮、不动全局；开始后模式/计时设置锁定
- 待办支持多条，加号可添加，点「…」可改名/改预计番茄数/删除；专注进行中不能切换到别的待办
- **聊天页**：所有模式都可进入，不支持聊天的模式只读；**回车只把消息放进聊天室**，点小飞机才请求角色回复（没字时让角色主动开口）；点气泡可引用/修改/撤回，角色气泡可整轮编辑/删除单条/重答
- 聊天页顶栏和输入栏固定，只有消息列表滚动；键盘弹出也不跑
- 聊天记录保存到 `fc:chat`；同一轮内（休息、下一个番茄）保留，手动结束或新开一轮清空
- 角色回复按行/`|||` 拆成多条气泡，空行和空括号会被丢弃；聊天设置可分别设最少/最多气泡
- `（动作/神态）` 去掉括号后作为整屏居中的灰色旁白，不套气泡、不受角色气泡宽度限制；聊天加号可开关旁白
- 点角色气泡可「编辑整轮」或「删除这条气泡」；整轮编辑一行一条，`（）` 自动作为旁白；用户消息不再提供重发
- 输入栏左侧加号：开始/暂停/继续、跳过、结束、旁白开关
- 不支持聊天的模式也能进入聊天室，只锁定输入框，仍可看历史
- 聊天设置从聊天页进入，返回固定回聊天页
- AI 回复可用 `[[extend:秒]]`、`[[mute:秒]]`、`[[lock:秒]]`、`[[password:四位数字]]` 触发监督动作，只有聊天设置里开启对应权限才执行
- **聊天设置**（聊天页右上角齿轮，无全局退出）：开始后默认进计时页/聊天室、主动说话开关与频率、动作/旁白开关、四项角色权限（加时/禁言/锁房间/改密码）、AI 气泡数、上下文条数、房间与锁、聊天/主动说话提示词、按角色兜底、控制台（完整 SYSTEM + 聊天室上下文 + token 估算）
- 点已开启的权限行打开配置弹窗，支持取消/保存：加时量/单次/累计、禁言最长、锁房间最短/最长/确认；设置页不再重复
- 控制台实时显示权限格式注入：开关打开出现 `[[extend]] / [[mute]] / [[lock]] / [[password]]`，关闭即消失
- **我的消息可修改**：点自己发的气泡 →「编辑这条」，后续对话用改后的文本，不改时间戳
- **聊天美化**（聊天设置最上方）：我的气泡 / 角色气泡 / 旁白的颜色、圆角、字号、气泡宽度、时间显示；带实时预览，3 套预设，颜色可「跟随主题」
- **格式提示词可自定义**：聊天、主动说话、便签、互动各有一份格式模板，默认只有气泡条数 / 旁白规则 / 已授权动作标签；支持 `{{bubble_min}} {{bubble_max}} {{narration}} {{permissions}}`，正文里写 `{{format}}` 就内联，不写则作为独立 system 追加
- **便签生成规则**：全部随机 / 只从勾选的样式里随机 / 固定某一款；旧数据默认仍是全部随机
- **便签高亮样式**：每款样式可单独设 `==高亮==` 的颜色与显示方式（马克笔 / 下划线 / 只改字色 / 实心块）
- 提示词支持 `{{format}}`（格式规则）与 `{{history}}`（上下文消息）占位符，点击插入
- **互动页**（B2 轻触 / C2 相伴）：与聊天页并列，从计时页「互动」进入，返回计时页；参考恋爱游戏主界面，全屏立绘 + 可点热区
- 立绘支持上传（长边压缩到 1080 存本机 `fc:portrait`）或填图片外链；热区在互动页右上角「编辑」里拖拽框选建立，支持矩形/椭圆、命名、拖动改范围
- 每个热区可配：本地台词（一行一句，随机取）、是否用 AI 回应、该部位补充设定、冷却秒数；同一点位有冷却，避免连点刷屏与连续计费
- 点触反馈显示为立绘下方气泡，同时写入聊天记录（`scene: 'touch'`），并累加未读
- 互动页底部「聊天」打开聊天小窗：列表 + 输入 + 小飞机，完全复用聊天室逻辑与美化，**不提供任何聊天配置入口**
- 互动提示词与互动格式提示词在聊天设置里改；点触阈值固定加时本期未做（见交接文档）
- 「修改密码」改为整行输入 + 整宽保存按钮，不再挤在标题旁
- 主动说话统一由「主动说话」开关控制，不再有「主动回应」重复开关
- **开始前**会弹「是否设置房间密码」：不设置 / 设置密码 / 让角色设置；聊天设置里只保留修改密码，不再有创建房间/角色设密码的重复项
- 全局设置里的角色改为「默认角色」；本轮开始后不可更换，中途改默认角色不会污染当前聊天上下文
- 聊天按角色隔离：换角色开始新专注会清空上一角色聊天；同一角色同一轮退出/重开 App 聊天仍在
- 专注进行中：模式卡、默认角色、计时设置全部置灰/锁定，点击给提示
- 锁房间支持最短/最长时长（0 = 锁到本轮结束），密码错误会在聊天里插入系统通知（第几次、猜的密码）
- 锁定时若没有密码会自动生成临时密码并显示在锁屏；锁屏同时显示专注剩余、锁定剩余、密码输入与最近消息
- 锁房间时角色不再主动说话，紧急退出仍保留
- **Token 账单**：设置页 → API 调用 → 查看；弹窗显示模型、输入/输出 token、耗时、上下文条数，可筛选成功/错误；AI 报错也会记录
- **每轮番茄数**：一轮包含 N 个专注；第 N 个专注后进入最终休息，休息结束本轮完成，不再自动开下一轮
- **最后一个番茄后直接长休息**开关：关闭则第 N 个专注后先短休息，休息结束本轮完成
- **记录与便签时机**：整轮结束才写一条历史并生成一次便签，不是每个专注都写；历史里保存本轮番茄数
- 专注/休息开始与结束都会在聊天里插入系统通知
- 提示词占位符可点击插入，记忆分四项：`{{memory_core}}` 核心记忆、`{{memory_long}}` 长期记忆、`{{memory_short}}` 短期记忆、`{{memory_vector}}` 向量记忆；另有 `{{format}}` 格式规则、`{{history}}` 上下文消息；不会自动注入宿主聊天
- 向量记忆优先用宿主 `memory.search` 召回最后一条发言相关内容；没有该接口或失败时退回 `longTerm.vectors`
- **统计**：月历 + 本月汇总 + 当天记录列表，点日期切换，点记录看详情
- **五种模式**：静室 / 守时 / 轻触 / 低语 / 相伴（内部 id 仍是 A/B1/B2/C1/C2，界面不再露代码）
- **便签墙**：仿真实便利贴（纸色、胶带、横线、随机角度），每次完成专注后角色写 1-2 句，按时间倒序；支持今天/本周/本月筛选与关键词搜索
- 便签支持 **加粗 / 斜体 / 高亮 / 删除线 / 下划线 / 遮盖**（`**x**`、`*x*`、`==x==`、`~~x~~`、`__x__`、`||x||`），遮盖点一下才显示
- 长按便签显示铅笔、调色板与垃圾桶：改内容、换样式或删便签（删便签不删专注记录）；提示词可自定义
- 便签样式：8 种内置预设（奶油/雾蓝/薄荷/樱粉/牛皮/月白/夜墨/草绿），每次生成随机抽取；可新建、编辑、删除自定义预设（纸色/文字/胶带/线条 + 横线/方格/点阵/空白 + 倾斜幅度）
- 快速测试：便签墙右上角「+」或空状态按钮可生成示例便签，示例不计入统计、可一键删除
- CSS 参考：项目根目录 `note-styles.css`（CSS 变量、纹理、内置配色与自定义示例）
- **聊天存档**：记录里最多保存本轮 20 条聊天，详情里可查看
- 编辑输入框/提示词时自动隐藏底部 Dock，避免被键盘顶住
- **设置页**新增 API 调用记录：最近 100 条，含场景、成功/失败、耗时、预估 token；可清空
- 锁房间支持房间密码：AI 改密码后，正常解锁需要输入密码，紧急退出仍然保留
- 计时页监督只有加时 / 禁言 / 锁房间；角色主动说话在聊天室，未读时「聊天」按钮显示红点

## 安装

在「小手机 → Settings → 插件 App 管理」里填 Manifest 链接：

```
https://raw.githubusercontent.com/chu-bing-yu/focus-companion/main/manifest.json
```

镜像（国内更稳，但有缓存延迟）：

```
https://cdn.jsdelivr.net/gh/chu-bing-yu/focus-companion@main/manifest.json
```

## 本地开发

```bash
npm install          # 只装 esbuild（devDependency）
npm run build        # src/ → plugin.js（单文件 IIFE），并自动归档到 releases/
npm test             # 核心逻辑单测（node --test）
npm run e2e          # 无头 Edge 端到端（先 build；用 dev/preview.html + 假宿主）
npm run deploy       # 发布到 GitHub（需要 GITHUB_TOKEN 环境变量）
```

浏览器预览（免安装）：

```
dev/preview.html            正式版
dev/preview.html?src=probe  宿主能力探针
```

预览使用 `dev/mock-host.js` 模拟 `roche.*`，数据存在 localStorage，不影响真机。

## 版本与回退

每次 `npm run build` 都会把产物复制到 `releases/v<版本号>/`（`plugin.js` / `manifest.json` / `README.md`），并刷新 `releases/index.json`。

```bash
npm run releases                     # 列出所有归档
npm run rollback -- 0.1.2            # 用 0.1.2 的产物回退，版本号自动 +1 patch
npm run rollback -- 0.1.2 --as 0.3.0 # 指定发布版本号
npm run deploy                       # 回退后同样要发布
```

说明：

- 回退只替换 `plugin.js` / `manifest.json` / `README.md`，**不改 `src/`**；之后继续开发时 `npm run build` 会回到当前源码。
- 宿主按版本号判断更新，所以回退时会自动把版本号改成更大的数（发布的是旧代码，版本号继续递增）。
- 修改版本号时要同时改 `package.json` 与 `manifest.json`，构建会校验两者一致。

## 数据

`roche.storage` 十个 key：`fc:settings`（schema 15） / `fc:session` / `fc:records` / `fc:tasks` / `fc:phrases` / `fc:logs` / `fc:chat` / `fc:chatOwner` / `fc:portrait`（互动立绘） / `fc:meta`。

**卸载插件时宿主会清空这些数据**，请在设置页定期「导出备份」。聊天记录存在 `fc:chat`，同一轮退出/重开 App 会保留；兜底语句按角色 ID 存在 `fc:phrases`。

## 约定

- 所有 `roche.*` 调用只允许出现在 `src/services/host.js`
- `src/core/*` 不碰 DOM、不读系统时间（时间由参数传入）
- 样式选择器全部以 `.fc-root` 开头，不改 `body/html`
- `mount` 里创建的定时器、监听、样式必须在 `unmount` 清理
- 监督动作（加时/禁言/锁房间/说话）只允许走 `services/supervisor.js`，规则在 `core/permissions.js`
- A 模式永不调用角色能力、永不锁房间；锁房间始终保留紧急退出
- AI 只走宿主 `ai.chat`，插件不保存任何 Key；提示词只存在本机存储
